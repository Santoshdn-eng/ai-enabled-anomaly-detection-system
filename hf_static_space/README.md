# 🛡️ AI Surveillance Anomaly Detector
### Deep Learning Action Recognition & Multi-Category Threat Detection Engine

An AI-powered video surveillance anomaly detection system featuring real-time action recognition, 15 anomaly categories, YOLOv8 pose keypoint tracking, facial expression analytics, and dynamic threat severity scoring.

## 🚀 Live Demo Features
- **15 Anomaly Categories**: Fighting, Fire, Smoke, Explosion, Guns, Weapons, Shooting, RoadAccidents, Traffic Irregularities, Burglary, Robbery, Shoplifting, Stealing, Abuse, and Normal Videos.
- **YOLOv8 Object & Pose Tracking**: Frame-by-frame 17-joint pose skeletons, target tracking IDs, and centroid motion trails.
- **Facial Expression AI**: 48x48 FER model mapping facial emotions to anomaly decision rules.
- **Multi-Channel Emergency Alert Station**: Real-time visual banners, desktop push notifications, and emergency sirens.
